# Publish PocketSmart worldwide

1. Create a GitHub repository and upload this project. Do not upload `Back end/AH.env`.
2. Sign in to Render and choose **New +** → **Blueprint**.
3. Select the GitHub repository. Render reads `render.yaml` and creates the web service.
4. In the service environment variables, add `GEMINI_API_KEY` with your private Gemini key.
5. Deploy. Render gives you an HTTPS address that works on Android, Windows, and any modern browser.

The public address is the only link you should share. Do not share your Gemini key.
